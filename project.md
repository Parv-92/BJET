# Smart Budget

## Purpose

Smart Budget is an automated personal budgeting application that
processes UPI payment receipts and categorizes transactions.

## Core Flow

Receipt Upload
→ OCR
→ Transaction Extraction
→ Merchant Identification
→ Category Prediction
→ User Confirmation
→ Budget Update

## MVP Features

- Upload UPI receipt screenshots
- Extract transaction information
- Automatically categorize expenses
- Allow category editing
- Store transactions
- Set category budgets
- Track monthly spending
- Show budget warnings

## Non-MVP Features

- Automatic notification scanning
- Bank account integration
- SMS parsing
- Advanced AI predictions
- Investment tracking
- Shared family budgets
